ArmorNGlory publishes an official, open-source Model Context Protocol (MCP) server and Scripture-to-Apparel knowledge base so AI assistants (Claude Desktop, ChatGPT, Gemini, Cursor, VS Code, Windsurf, and Antigravity) can search verified live products, explain the biblical context behind each design, check garment sizing, and build 1-click checkout links without hallucinating.

1. Quick Install (Claude Desktop, Cursor, VS Code, Windsurf, Antigravity)

Add the official armornglory-mcp-server package from npm (no API key required, 100% free):

{
  "mcpServers": {
    "armornglory": {
      "command": "npx",
      "args": ["-y", "armornglory-mcp-server@latest"]
    }
  }
}

Or with Claude Code CLI:

claude mcp add armornglory -- npx -y armornglory-mcp-server@latest

2. What AI Agents Can Do With the ArmorNGlory MCP

  • Scripture & Christian Symbolism Concordance: Look up passages and marks (Romans 8:37 More Than Conquerors, Exodus 3:5 Holy Ground, Ephesians 6 Armor of God, Isaiah 40:31 Second Wind, 1 Corinthians 10:31 Every Rep His Glory, Est. 33 AD) or search by life season (courage, anxiety, baptism, grief, gym training).
  • Live Catalog Search: Filter 330+ active Christian streetwear pieces—5-panel trucker hats, Comfort Colors 1717 heavyweight tees, fleece hoodies, tough magnetic phone cases (iPhone MagSafe & Samsung Galaxy S26 series), stainless steel water bottles, pajama loungewear, and wall art—by verse, color, size, occasion, or budget.
  • Faith Milestone Gift Curation: Personalized recommendations for baptisms, confirmations, Father's Day, Mother's Day, pastor appreciation, Christmas, and Easter.
  • Editorial Style & Fit Guides: Sizing charts, garment GSM & care instructions, and casual church outfit guides.
  • 1-Click Checkout Permalinks & Native UCP: Instant Shopify cart links, complementing our native Universal Commerce Protocol (UCP) endpoint at https://armornglory.com/api/ucp/mcp.
